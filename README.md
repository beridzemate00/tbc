# Northstar Studio Landing Page

A modern, responsive landing page built with plain HTML, CSS, and JavaScript. The page includes a hero section, about section, three feature cards, and a contact form with basic client-side validation.

## Project Structure

- `index.html` — page structure and content
- `style.css` — responsive styling and modern visual design
- `script.js` — form validation and dynamic footer year

## Local Preview

1. Open a terminal in the project folder.
2. Run:

```bash
python3 -m http.server 8000
```

3. Open `http://localhost:8000` in your browser.

## GitHub Pages Deployment

1. Push this project to a GitHub repository.
2. In the repository, go to **Settings** > **Pages**.
3. Under **Source**, choose **Deploy from a branch**.
4. Select the branch you want to publish (for example `main`) and the root folder `/`.
5. Save the settings.
6. GitHub Pages will provide a live URL for the site.

## Notes

- The layout is mobile-friendly and scales well across desktop, tablet, and phone screens.
- There are no external frameworks or libraries.
- The contact form includes basic validation to ensure required fields are filled in correctly.
